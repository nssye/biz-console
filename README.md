# 事業コンソール

商品・工程・タスク・ツール探索・情報収集を1画面で管理し、Claude Codeに作業を渡せる管理画面です。
データは `data/biz.json` の1ファイルです。画面もClaude Codeも同じファイルを読み書きします。

## はじめかた(3ステップ)
1. このフォルダを、パソコンの好きな場所に置く(例: `C:\Users\あなた\biz-console`)。
   - Documents や Desktop などの「フォルダそのもの」は接続できません。その中に置いたフォルダを使ってください。
2. `index.html` を **Chrome か Edge** で開き、「フォルダを接続」でこのフォルダを選ぶ。
   - 画面上部に「保存済み」と出れば接続できています。次回からは、開くたびに「再接続する」を1回押します。
3. VS Code でも同じフォルダを開き、Claude Code に `/biz-queue` と入力する。
   - 画面で「Claudeに依頼」した内容を、Claude Codeが順に処理して画面に書き戻します。

最初はサンプルデータが入っています。試し終わったら、画面上の「サンプルをすべて削除」で消せます。

## 画面
| 画面 | できること |
|---|---|
| 全体 | 数字、工程ごとの商品数、次にやること、判断日を過ぎた商品、Claudeに渡す依頼 |
| 工程表 | 商品を行、工程を列にした表。マス目を押すと、その工程に移る |
| 商品 | 検索・絞り込み・並べ替え。表示する列を選べる。行を押すと全項目を編集できる |
| タスク | 未着手・進行中・完了。ドラッグで移動。担当は「自分」か「Claude Code」 |
| ツール探索 | 候補の一覧と比較。Claudeに探させたり、調べさせたりできる |
| 情報収集 | URLやメモを貼って保存。新着をまとめてClaudeに整理させられる |
| Claude連携 | つなぎ方、依頼の待機状況、活動ログ、データの書き出し・読み込み |

## Claude Codeのコマンド
| コマンド | 内容 |
|---|---|
| `/biz-queue` | 待機中の依頼をすべて処理する(`/biz-queue t-xxxx` でその1件だけ) |
| `/biz-product-new` | 商品を追加し、成果物フォルダの雛形を作る |
| `/biz-tool-scout` | 目的に合うツールを探して比較し、ツール探索に追加する |
| `/biz-weekly-report` | 週次レポートを `reports/` に作る |

`/` のコマンドが出ない場合は、画面の「Claude連携」にある文章をそのまま貼ってください。

## GitHubに上げるとき
Claude Codeに「このフォルダをGitHubの **private** リポジトリに上げて」と頼んでください。
`data/biz.json` には事業の計画や売上が入るので、公開(public)にはしないことをおすすめします。

## ファイル構成
```
index.html        管理画面(これだけでも動きます)
data/biz.json     すべてのデータ
CLAUDE.md         Claude Codeへのルール
docs/SCHEMA.md    データの項目の説明
.claude/          Claude Codeのスキル(/biz-queue など)と権限設定
products/         商品の成果物
reports/          週次レポート
```
