# ツール探索

引数が目的(例: 英語圏でデジタル商品を売りたい)。なければ何をしたいかを1回だけ聞く。

## 手順
1. `CLAUDE.md` と `docs/SCHEMA.md` を読む。`data/biz.json` の `tools` を読み、すでにあるものは重複して追加しない。
2. Web検索で候補を5つ見つける。公式サイトを優先し、**料金・手数料・規約上の注意・日本から使えるか・代替**を、最新のページで確認する。
3. 各候補を `tools` に追加する。
   - `status`: `気になる`、`category`: 近いもの
   - `cost`: 確認できた料金・手数料(確認日つき)。確認できなければ「未確認」
   - `pros` / `cons`: 事実だけを書く
   - `affiliate`: アフィリエイトプログラムの有無(確認できた場合のみ)
   - `notes`: 出典URLと確認日(YYYY-MM-DD)
4. `log` に「ツール候補を追加: <名前>」を足す。
5. 最後に、チャットで比較を5行以内にまとめ、おすすめの1つと理由を伝える。料金や規約は変わるので、契約前に公式で再確認するよう添える。

## 注意
- 口コミや比較サイトの数字は、公式で確認できるまで確定として書かない。
- アカウント作成・申し込み・支払いは実行しない。
