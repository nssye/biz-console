# 週次レポート

## 手順
1. `data/biz.json` を読む。今日の日付(日本時間)を確認する。
2. 次の内容を集計する。
   - 工程ごとの商品数(撤退を除く)と、この1週間で工程が進んだ商品(`log` から)
   - 出品済みで `listedAt` から `meta.decisionDays` 日以上たち、`sales` が0の商品(判断日を過ぎたもの)
   - 売上: 通貨ごとの `revenue` の合計、販売があった商品
   - 完了したタスク、期限切れのタスク、Claude Codeの待機中の依頼
   - 新着の `intel` の件数と、使える度が高いもの
3. `reports/YYYY-MM-DD.md` に、やさしい日本語で保存する。構成は「今週の動き / 判断が必要なもの / 数字 / 来週の一手(3つまで)」。
4. 来週の一手は、新しい商品を増やすことより「判断日を過ぎた商品の決断」と「売れ始めた型の横展開」を優先して考える。数字が少なく根拠が足りないときは、そう書く(推測で盛らない)。
5. `log` に「週次レポートを作成: reports/YYYY-MM-DD.md」を足し、チャットで3行以内に要点を伝える。
